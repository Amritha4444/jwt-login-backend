# JWT Login System - Node.js Backend

This project is the Node.js backend for a full-stack JWT Login System. It provides user authentication using Express.js, SQLite database, and JSON Web Token (JWT).

## Technologies Used

- Node.js
- Express.js
- SQLite
- JSON Web Token (JWT)
- CORS

## Features

- User login using email and password
- SQLite database integration
- JWT token generation after successful login
- JWT authentication middleware
- Protected Dashboard API
- CORS support
- Database created automatically when the server starts
